What is ProMonitor?

Machine data, turned into applications people use

ProMonitor is a modular industrial software platform developed by VAMS Mechatronica. A common core connects to industrial equipment, stores machine data and manages assets, users, alerts and events. Applications built on that core then answer specific questions: what the machines are doing, what is being produced, and what is likely to fail.

It is a software product, not a consulting service or a single dashboard — VAMS Mechatronica also provides the industrial automation and integration work that connects it to your factory.

Deployment and integration

SaaS in the cloud, or on-premise

SaaS (cloud)Hosted service; connect your machines to it.
On-premiseInstalled inside your plant network.

ProMonitor runs as a set of Docker containers: the API, background workers, the connectivity agent, the machine-learning service and the data stores. Other systems reach it through a REST API and a live WebSocket stream, and a Kafka bridge can feed it existing telemetry.
